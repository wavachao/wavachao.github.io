原题

当 A 的子数组 A[i], A[i+1], …, A[j] 满足下列条件时，我们称其为湍流子数组：

若 i <= k < j，当 k 为奇数时， A[k] > A[k+1]，且当 k 为偶数时，A[k] < A[k+1]；

或 若 i <= k < j，当 k 为偶数时，A[k] > A[k+1] ，且当 k 为奇数时， A[k] < A[k+1]。

也就是说，如果比较符号在子数组中的每个相邻元素对之间翻转，则该子数组是湍流子数组。

返回 A 的最大湍流子数组的长度。

示例 1：

输入：[9,4,2,10,7,8,8,1,9]
输出：5
解释：(A[1] > A[2] < A[3] > A[4] < A[5])

示例 2：

输入：[4,8,12,16]
输出：2

示例 3：

输入：[100]
输出：1

提示：

  1. $1 <= A.length <= 40000$
  2. $0 <= A[i] <= 10^9$

题解

这个题就是要我们找有波形的数组，比如：

换句话说，我们只要找这种波浪形数组，求个最大值就行了~

比如数组 $[9,4,2,10,7,8,8,1,9]$

可以拆分成 $[9], [4, 2, 10, 7, 8], [8, 1, 9]$

步骤

  1. 判断 $(A[i - 1] \times A[i]) \times (A[i] \times A[i + 1]) == -1$ 是否成立
    1. 如果成立，说明是湍流子数组，滑动窗口
    2. 如果不满足，更新边界，更新湍流子数组最大值

代码

  • C++代码
class Solution {
private:
    int cmp(int x, int y) {
        if (x < y) {
            return -1;
        } else if (x == y) {
            return 0;
        } else {
            return 1;
        }
    }
public:
    int maxTurbulenceSize(vector<int>& A) {
        int size = A.size();
        int ans = 1;
        int p = 0;
        for (int i = 1; i < size; ++i) {
            // 判断下A[i - 1]和A[i]那个大
            int c = cmp(A[i - 1], A[i]);
            // 如果 A[i - 1] > A[i] < A[i + 1] or A[i - 1] < A[i] > A[i + 1]
            // 他们的乘积肯定不为-1，说明是湍流子数组
            if (i == size - 1 || c * cmp(A[i], A[i + 1]) != -1) {
                if (c != 0) {
                    ans = max(ans, i - p + 1);
                }
                p = i;
            }
        }
        return ans;
    }
};

class Solution:
    def maxTurbulenceSize(self, A: List[int]) -> int:
        def cmp(x, y):
            if x < y:
                return -1
            elif x == y:
                return 0
            else:
                return 1

        size = len(A)
        ans, p = 1, 0
        for i in range(1, size):
            c = cmp(A[i - 1], A[i])
            if i == size - 1 or c * cmp(A[i], A[i + 1]) != -1:
                if c != 0:
                    ans = max(ans, i - p + 1)
                p = i
        return ans
