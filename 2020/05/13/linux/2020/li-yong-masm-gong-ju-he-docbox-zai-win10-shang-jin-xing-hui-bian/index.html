2.安装DOCBOX

1）运行，一路next即可。

2）在另一个盘创建个专门汇编的文件夹，列如：E:\Assembly。

3）把网盘下载的masm工具放该文件夹，或者直接解压官网的masm32v11r，安装后直接用gedit.exe程序编写、编译和链接asm汇编程序。

4）点击桌面的DOCbox0.74-3。

mount c E:\Assembly
c:
cd 汇编文件目录

5）不想每次都输入上步骤，可这样

在DOCBOX安装目录下找到DOSBox 0.74 Options.bat

在弹出来的文档最下面输入

mount c E:\Assembly
path=%path%; \asm

asm是在Assembly下保存汇编的文件夹，另外一个masm是用来保存汇编工具的。

接下来就可以进行汇编了。

alt+enter全屏模式！

列如

cd /asm
masm test,asm
敲入回车

敲入回车
link test.obj
debug test.exe
