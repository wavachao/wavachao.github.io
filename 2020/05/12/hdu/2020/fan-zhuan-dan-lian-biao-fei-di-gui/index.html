链表定义：

struct ListNode {
         int val;
         ListNode *next;
  };

先上代码，再解释！

/*初始链表：1 -> 2 -> 3 -> nullptr
 *目标链表：3 -> 2 -> 1 -> nullptr
 */

struct ListNode reverse(ListNode *head) {
    ListNode *node = nullptr;
    while(cur) {
        ListNode *cur = head->next;    //保存head->next结点信息
        head->next = node;            //反转指向
        node = head;                //后移node
        head = cur;                    //后移head
    }
    return node;
}
初始链表:       1   ->   2   ->   3   ->   nullptr

第一步:         node             head     cur
                \             \        \
                nullptr   ->   1   ->   2   ->   3 
                node             head      cur
                \             \        \    
第二步 :         nullptr   <-   1        2   ->   3 
                        node(head)      cur        
                              \        \
第三步 :            nullptr   <-  1        2   ->   3 
                            node    head(cur)
                               \        \
第四步 :         nullptr   <-   1        2   ->   3 

完成了第一次循环!
然后重复上面的步骤直到cur为nullptr，此时易知node指向3结点。
链表反转完成，新的链表为node!
