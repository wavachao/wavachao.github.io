Vscode都配置好了，接下来设置一个有趣的个性化背景。

如果没有安装好C++编译环境可以参考：Visual Studio Code配置C/C++环境(win10)

1.搜索插件background

安装好了以后会出现插件破损的提示，别理，设置为不再提醒。

2.配置

打开全局配置，添加如下内容：

"background.enabled": true,
"background.useDefault": false,
//是否使用默认图片
"background.customImages": [
    "file://D:/2345Downloads/png/Live.png",
    "file://D:/2345Downloads/png/Live2D1.png",
    "file://D:/2345Downloads/png/Live2D2.png",
    //"file://D:/2345Downloads/png/1.jpg",//图片路径
],
"background.style": {
    "content": "''",
    "pointer-events": "none",
    "position": "absolute",
    "z-index": "99999",
    "width": "100%",
    "height": "100%",
    "background-position": "100% 100%",
    "background-repeat": "no-repeat",
    "opacity": 0.35
}

然后就好了。上张图：
