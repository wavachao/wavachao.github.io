Ubuntu20.04

安装NFS服务器端

sudo apt-get install nfs-kernel-server

设置共享目录

mkdir -p /home/incipe/nfs
sudo chmod 777 /home/incipe/nfs
sudo vim /etc/exports
# 添加如下内容
/home/incipe/nfs (rw)

重启NFS服务

sudo /etc/init.d/nfs-kernel-server restart

开发板挂载

如果没有NFS客户端请先移植NFS客户端。

输入一行命令即可共享文件了。

mount -t nfs 113.223.44.99:/home/incipe/nfs /mnt/sd -o nolock

这里的ip根据自己的实际情况定，服务器ip是多少就是多少，/mnt/sd 是共享的文件的目录，可根据需求更改。
